첫구매 고객은 전용 상품을 쓰고 있는가

기존 지표는 [첫 구매 전용] 상품이 얼마 팔렸나만 봤다. 고객의 구매회차와는 무관한 숫자였다. 이 화면은 반대쪽을 본다 — 주문의 first_order 가 T 인 고객(그 회원의 첫 주문)이 실제로 무엇을 담았는지, 그래서 전용 라인업에 어떤 빈칸이 있는지.

창 비교 — 같은 라인업이 기간에 따라 정반대로 읽힌다

행사(클리어런스) 기간에는 [N+M] 번들이 첫구매를 점령해 전용 상품이 구조적으로 죽은 것처럼 보인다. 그래서 라인업 판단의 기준은 평상시 창이고, 행사 창은 대조용이다.

평상시 창 요약

커버리지 = 전용 상품을 담은 첫구매 주문 / 전체 첫구매 주문. 객단가는 주문 전체 결제금액 평균이다.

첫구매 상품 랭킹과 라인업 빈칸

사은품(gift=T, 전체 품목의 16%)은 제외했다. 안 빼면 사은품 암슬리브가 침투율 54%로 1위가 되어 "사은품을 전용 상품으로 만들자"는 결론이 나온다.

전용 상품 일반 — 전용 쌍둥이 있음 일반 — 전용 없음(후보군)

첫구매 주문수 상위 상품

막대 길이 = 그 상품을 담은 첫구매 주문수

갭 매트릭스

가로 침투율 · 세로 첫구매지수 · 점 크기 매출. 우상단의 회색 점이 전용 후보다

전용 라인업 판정

흡수율 = 전용 첫구매주문 / (전용 + 짝 일반상품 첫구매주문). 전용이 0건이어도 짝 일반상품이 잘 팔리면 그건 수요 없음이 아니라 전용으로 오지 않음이다 — 진열 제외가 아니라 노출·가격 문제다.

액션

평상시 창 전부에서 나타난 신호만 실행 대상으로 본다. 행사 창에서는 번들이 전용 수요를 눌러 신호가 사라지므로, 행사 창의 부재는 반증이 아니다.

보류 — 일부 창에만 나타남

전용 상품 일별 매출 · 기존 지표

기존 루틴이 매일 적재해 온 공급 측 지표. 정의가 달라 위 숫자와 직접 비교되지 않는다 — 여기 매출은 라인아이템 기준, 객단가는 그 상품이 포함된 주문의 전체 결제금액 평균이다.
